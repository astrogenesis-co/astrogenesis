# Albums

An album is a concept. Each track is planned in advance as part of that concept: the album file states the idea and the track sequence before the music is finished.

Songs are worked on (in [`songs/`](../songs/)), then tracks are made from songs — a track is a song realized inside the album's structure. Each track corresponds to a stage of the album's narrative arc, detailed in [`stages/`](../stages/), and each stage gets an essay in [`essays/`](../essays/).
